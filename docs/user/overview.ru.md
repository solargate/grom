# Обзор для пользователя

Flutter-клиент Grom работает как **веб-UI** и как приложение для **Android**. Веб-UI отдаёт тот же процесс `grom`: откройте базовый URL сервера в браузере (например `http://localhost:8080/` с конфигом для разработки по умолчанию). Экраны и сценарии совпадают с Android; живая GPS-запись доступна только на Android. Строки UI есть на английском, русском и немецком.

Если вы не вошли в аккаунт, на **Home** / «Главная» показывается приветственный экран с логотипом Grom, кратким описанием и кнопками **Sign in** / «Вход» и **Register** / «Регистрация». На Android в тексте также напоминание указать адрес сервера Grom при входе.

На **Android** (и позже iOS) при входе и регистрации запрашивается **URL сервера**. Можно указать голый хост, например `grom.example.com` (без `https://`), или открыть список рядом с полем и выбрать [одобренный публичный сервер](approved-servers.md) либо тот, к которому вы уже подключались. При отправке приложение проверяет `GET /api/v1/status` сначала по HTTPS, затем по HTTP, подставляет найденный URL в поле и продолжает. Если вы уже ввели `http://` / `https://` или явный порт, значение используется как есть. **HTTP поддерживается для локальных / LAN-инстансов** без TLS; для всего, что доступно из интернета, предпочтителен HTTPS.

## Вход и сброс пароля {#sign-in-and-password-reset}

Если оператор включил исходящую почту (`mailer` в конфиге сервера), на экране входа показывается **Forgot password?** / «Забыли пароль?». Введите email аккаунта; сервер отвечает одинаково, зарегистрирован адрес или нет. Проверьте почту: ссылка для сброса открывается в **браузере** (веб-UI по адресу `/reset-password`). После установки нового пароля войдите снова в приложении или в вебе. Сброс пароля недоступен, если сервер сообщает `password_reset_enabled: false`.

Когда оператор включает captcha (`auth.captcha.enabled`), на входе, регистрации и «забыли пароль» появляется чекбокс **I'm not a robot** / «Я не робот». Отметьте его и дождитесь локальной проверки proof-of-work перед отправкой (на слабых устройствах это может занять время). Установка нового пароля по ссылке из письма captcha не требует.

## Профиль и удаление аккаунта {#profile-and-account-deletion}

В **Profile** / «Профиль» через меню переполнения можно изменить профиль или **Delete account** / «Удалить аккаунт». Полные шаги, какие данные удаляются и заметки по федерации: [Удаление аккаунта Grom](delete-account.md).

Эта страница — краткий тур по основным экранам (скриншоты ниже — с Android). Настройка сервера (установка, конфиг, TLS, федерация) — в [документации для администраторов](../README.md#admin). HTTP API: Swagger на `/api/docs/` на работающем сервере.

## Тренировки {#workouts}

Домашняя лента показывает активности с типом, датой, устройством, дистанцией/временем (и темпом или набором высоты, когда уместно), плюс превью карты при наличии GPS-трека. На вкладке **My workouts** / «Мои тренировки» можно фильтровать список по виду спорта: иконка фильтра в шапке (только на этой вкладке, если у вас уже есть использованные виды спорта) открывает переключатели этих видов. На той же вкладке есть переключатель список/карточки (рядом с фильтром, если он показан): в компактных строках — иконка вида спорта, дата, название и дистанция или длительность в зависимости от категории; выбор сохраняется на устройстве. На каждой карточке под картой и фото — социальная панель: слева лайки (палец вверх — лайк/анлайк чужой тренировки; по счётчику — кто лайкнул), справа комментарии (счётчик + иконка). Свои тренировки лайкать нельзя; кнопка лайка на них неактивна. Комментировать можно свои и чужие. По иконке комментариев открывается тред: добавить комментарий (до 1000 символов) или удалить свой (владелец тренировки может удалить любой комментарий к ней).

![Список тренировок на Android](../screenshots/workout-list.jpg)

Откройте тренировку для полной карточки: интерактивная карта (если есть трек), галерея фото, та же социальная панель, график скорости по дистанции со средним и максимумом и график пульса (по дистанции при GPS, иначе по прошедшим минутам) со средним и максимумом ЧСС. Тап по графику показывает значения в точке.

Тренировки можно создавать вручную, импортировать треки GPX/FIT, прикреплять фото и связывать снаряжение. При редактировании можно добавлять и удалять фото (до 20). При создании имя по умолчанию — локализованный тип спорта и следует за сменой спорта, пока вы его не отредактируете. На Android также можно записать живой GPS-трек (см. ниже).

## Живая запись (Android) {#live-recording-android}

Откройте **Add workout → Record** / «Добавить тренировку → Запись», чтобы вести маршрут на карте с живой длительностью, скоростью и дистанцией. Держите уведомление записи, пока сессия активна. Автопаузу можно включать и выключать.

## Снаряжение {#equipment}

Управляйте велосипедами, обувью и другим снаряжением. Элементы сгруппированы по категориям; суммарная дистанция накапливается по мере использования на тренировках (в том числе после массового импорта Strava).

## Социальные функции и федерация {#social-and-federation}

Подписывайтесь на пользователей того же инстанса и смотрите общую ленту. Лайкайте и комментируйте тренировки тех, на кого подписаны (локально или через федерацию); счётчики видны в списке и на детальной странице.

Если оператор включает федерацию ActivityPub, можно также подписываться на спортсменов на других инстансах Grom (на сервере нужен HTTPS). Лайки удалённых тренировок уходят как ActivityPub `Like`; снятие лайка — `Undo`. Комментарии к удалённым тренировкам — `Create` Note с `inReplyTo`; удаление комментария — `Delete`. Входящие лайки и комментарии с других инстансов обновляют локальную тренировку так же. Удаление аккаунта и поведение федеративного `Delete` актора описаны в [Удаление аккаунта Grom](delete-account.md).

## Импорт Strava {#strava-import}

В **Integration → Strava** загрузите ZIP [массового экспорта данных Strava](https://support.strava.com/hc/en-us/articles/216918437-Exporting-your-Data-and-Bulk-Export). Grom импортирует активности, треки, фото и снаряжение. Сопоставление колонок и поведение на сервере — в [Массовый импорт Strava](../integrations/strava-bulk-import.md).

Только на **Android** можно также включить **Импорт тренировок из Strava** со своими Client ID/Secret API-приложения Strava, один раз подключиться через OAuth и использовать кнопку синхронизации на Главной (до 10 последних активностей, стоп на первой уже импортированной). Подробности: [Импорт через Strava API](../integrations/strava-api-import.md).

## Импорт треков {#import-tracks}

В **Integration** → **External services** блок **Импорт треков** открывает системный выбор одного или нескольких файлов `.gpx` / `.fit` (web и Android). Подробности и дедуп `external_id`: [Импорт треков](../integrations/import-tracks.md).

# Импорт Health Sync + Google Drive (Android)

Android-приложение Grom может импортировать тренировки, которые [Health Sync](https://healthsync.app/) экспортировал в Google Drive. Этот сценарий **только для Android**; в веб-UI его нет.

## Сценарий пользователя

1. В Health Sync настройте синхронизацию активностей **в Google Drive**. Health Sync создаёт папку на Drive (обычно `Health Sync`) и пишет CSV-сводки по активностям плюс файлы треков (предпочтительно FIT; GPX/TCX/KML при наличии GPS).
2. В Grom откройте **Integration**.
3. Включите **Health Sync + Google Drive sync**. Войдите в Google и выдайте доступ к Drive только на чтение. Grom ищет папку, в имени которой есть `Health Sync`, и заполняет **Health Sync folder**.
4. При желании измените имя папки (точное совпадение при синхронизации) или нажмите иконку поиска папки, чтобы снова выбрать первую папку Drive, подходящую под `Health Sync*`.
5. На **Home** нажмите иконку синхронизации в шапке. Grom импортирует новые тренировки и обновляет список.

## Что импортируется

Для каждого CSV активности в папке:

| Колонка CSV (по индексу) | Использование в Grom |
|--------------------------|----------------------|
| 1 Source app | Часть `external_id.name` как `health-sync/{source}` |
| 2 Sport | Сопоставление с типом спорта Grom |
| 3 Title | Имя тренировки |
| 4 Date/time | Время старта (локальный часовой пояс устройства; при наличии трека побеждают значения трека) |
| 6 Elapsed | `duration_total_seconds` (трек может переопределить) |
| 7 Moving | `duration_seconds` (трек может переопределить) |
| 8 Distance (km) | Запасной вариант, если у трека нет дистанции |

Сопоставление трека использует спорт + дату + время из имени CSV: предпочтительно `{date} {time}-{SPORT}.fit`, иначе `.gpx`. Активности только с CSV (без трека) тоже создаются.

Уже импортированные строки пропускаются по `external_id` (`name` + имя CSV-файла как `id`).

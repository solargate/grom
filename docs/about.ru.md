# О проекте

> **Grom — свободная экосистема тренировок: ваш сервер, ваши сообщества, открытый код.**

**Миссия Grom** — дать спортсменам и любителям независимую, свободную среду вокруг тренировок: не привязанную к одному облаку и не закрытую чужими правилами.

Grom можно установить лично или для клуба, команды, города — у каждого сообщества свой инстанс и свои данные. Федерация соединяет эти инстансы: подписки, лента, лайки и комментарии работают не только внутри одной площадки, но и между сообществами. При этом Grom не претендует на роль единственного источника правды о ваших тренировках: он принимает GPX и FIT, умеет импортировать данные из привычных спортивных сервисов и открывает API для своих скриптов и приложений.

Код проекта открыт ([GPL-3.0](https://github.com/solargate/grom/blob/master/LICENSE)): любой может запускать, изучать, улучшать и участвовать в развитии — чтобы экосистема росла вместе с теми, кто ей пользуется.

## Опоры {#pillars}

| Опора | Что это значит |
|-------|----------------|
| **Свобода** | Полностью свободная экосистема для спортсменов и любителей — без обязательного центрального сервиса. |
| **Владение** | Сервер для себя или для любого сообщества; данные остаются у оператора инстанса. |
| **Сообщество** | Обмен тренировками и социальными сигналами между инстансами (ActivityPub). |
| **Связность** | Интеграции с доступными спортивными сервисами, форматами треков и API. |
| **Участие** | Open source: любой может пользоваться, форкать и развивать проект. |
